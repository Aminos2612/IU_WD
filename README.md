# 📘 IU_WD – Advanced Workbook for Web Application Development

This repository contains all source code, documentation, and scripts submitted as part of the **Advanced Workbook** for the course **Web Application Development (CSEBCSWAD01)** at **IU International University of Applied Sciences**.

---

## 📂 Repository Structure

```
IU_WD/
├── index.html               # Task 5: Book List Manager web application
├── git-workflow-example.sh # Task 2: Git DVCS workflow example with documentation
└── README.md                # This file
```

---

## ✅ Task Highlights

### Task 2: Git as a DVCS
- Demonstrates Git configuration, initialization, staging, committing, and pushing to GitHub
- Explains Git object types (commits, trees, blobs) with inspection commands
- File: `git-workflow-example.sh`

### Task 5: Book List Manager
- Fully responsive, styled HTML/JavaScript application
- Allows viewing, updating, and removing books from a JSON dataset
- Uses form validation and dynamic DOM updates
- File: `index.html`

Live Preview: 👉 [View on GitHub Pages](https://aminos2612.github.io/IU_WD/)
