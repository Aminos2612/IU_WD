## ✅ Task Highlights

### Task 2: Git as a DVCS
- Demonstrates Git configuration, initialization, staging, committing, and pushing to GitHub
- Explains Git object types (commits, trees, blobs) with inspection commands
- Run it: `bash git-workflow-example.sh [remote-url]` (push steps are skipped when no remote URL is given)
- File: `git-workflow-example.sh`

### Task 3: BookNest Online Bookstore
- Static page built with semantic HTML5 elements (`header`, `nav`, `main`, `section`, `footer`)
- Featured book sections with cover images and descriptive alt text
- File: `task3_bookstore.html`

### Task 5: Book List Manager
- Fully responsive, styled HTML/JavaScript application
- Allows viewing, updating, and removing books from a JavaScript array of book objects
- Partial updates: only the fields you fill in are changed
- Uses form validation and safe dynamic DOM updates
- File: `index.html`

Live Preview: 👉 [View on GitHub Pages](https://aminos2612.github.io/IU_WD/)
